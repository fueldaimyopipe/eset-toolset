## 🔐 Privacy & Account Security

Review everyday practices that help protect personal information.

- Use strong, unique passwords.
- Enable multifactor authentication where available.
- Review account recovery options.
- Check application permissions and startup entries.
- Remove software that is no longer needed.
- Avoid storing credentials in plain-text files.
- Review browser extensions and their permissions.

## 🌐 Network & Firewall Checklist

Document basic network security settings.

- Record firewall status and relevant rules.
- Review applications allowed to communicate through the firewall.
- Document trusted network profiles.
- Investigate unexpected connection alerts using reputable tools.
- Keep router firmware updated where applicable.
- Avoid disabling firewall protection as a routine troubleshooting shortcut.

Only change network rules when you understand the effect and have authorization to manage the device.

## 🚨 Incident Response Planner

Use a structured checklist when suspicious activity occurs.

1. Record the alert and the time it appeared.
2. Avoid entering sensitive credentials on potentially compromised systems.
3. Run a scan using a trusted security product.
4. Follow the vendor's quarantine and remediation instructions.
5. Change affected credentials from a trusted device if compromise is suspected.
6. Preserve relevant logs and evidence.
7. Restore files from a verified backup if necessary.
8. Contact the appropriate IT or security support team for serious incidents.

For suspected ransomware or an active compromise, prioritize containment and professional guidance rather than experimenting with unknown repair utilities.

## 💾 Backup & Recovery

Prepare for unexpected failures and security incidents.

- Record backup locations and completion dates.
- Keep important data protected with an appropriate backup strategy.
- Maintain a separate or offline backup where practical.
- Verify that backups can be restored.
- Document recovery media and procedures.
- Keep backup credentials secure.

A backup is only useful if the data can be recovered successfully.
